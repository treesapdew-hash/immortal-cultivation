filename in its heading, into `assets/ui/titles/`.

`Sovereign of the Ring.png` — the game looks the art up by id.

512×128 spec, so nothing needs adding. If a result comes back with
lettering on it, regenerate rather than editing it out: the name is
drawn in code over the banner.
